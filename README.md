# Finance Clarity App - プロトタイプ

要件定義書に基づいた、収入・支出バランス特化型家計簿アプリのプロトタイプです。

## 🎯 コンセプト

- **高速入力**: テンキー固定、金額による費目予測、自動保存
- **美しい可視化**: ダークモード、洗練されたグラフ、データドリブンな分析

## ✨ 実装済み機能

### 1. 高速入力画面 (InputScreen)
- ✅ 画面下部固定のカスタムテンキー（000ボタン含む）
- ✅ リアルタイム金額プレビュー
- ✅ 金額による費目予測（過去履歴ベース）
- ✅ 8つの固定費目ボタン（位置固定）
- ✅ 第2階層サブカテゴリー選択モーダル
- ✅ 確定ボタンなしの自動保存
- ✅ 保存時のフェードアウトアニメーション

### 2. 分析画面 (AnalysisScreen)
- ✅ 家計の健康スコアカード（A+〜D評価）
- ✅ 貯蓄率ドーナツグラフ
- ✅ 対前月比較ヒストグラム
- ✅ 目標達成度プログレスバー
- ✅ リアルタイム収支サマリー

### 3. 収入管理画面 (IncomeScreen)
- ✅ 収入の追加・削除
- ✅ 定期収入の設定
- ✅ 収入履歴の表示
- ✅ 合計収入の可視化

### 4. データ永続化
- ✅ SharedPreferencesによるローカルストレージ
- ✅ 無制限のデータ保存期間
- ✅ 費目予測のための統計データ分析

## 🚀 実行方法

### 前提条件
- Flutter SDK (3.0.0以上)
- iOS Simulator または Android Emulator

### インストールと起動

```bash
# プロジェクトディレクトリに移動
cd finance_clarity_app

# 依存関係のインストール
flutter pub get

# アプリの起動
flutter run
```

## 📱 画面構成

### ボトムナビゲーション
1. **分析** - 財務データの可視化と健康スコア
2. **入力** - 高速支出記録（メイン画面）
3. **収入** - 収入管理と履歴

## 🎨 デザインテーマ

- **カラー**:
  - 背景: `#050505` (ダークブラック)
  - カード: `#1A1A1A` (ミディアムブラック)
  - アクセント: `lightBlueAccent` (#80D8FF相当)
- **フォント**: Inter (想定)
- **スタイル**: Swiss Modern & Data Clarity

## 📊 データモデル

### Transaction (支出記録)
- id, date, amount, mainCategoryId, subCategoryId, tags, note

### Income (収入記録)
- id, date, amount, incomeType, isRecurring

### Category (費目)
- 第1階層: 8つの固定費目（食費、住居、交通、娯楽、衣服、医療、通信、その他）
- 第2階層: カスタマイズ可能なサブカテゴリー

## 🔄 主要なUXフロー

### 支出入力フロー
1. 金額をテンキーで入力
2. 予測された費目が自動ハイライト
3. 費目をタップ
4. サブカテゴリーを選択（モーダル）
5. 自動保存 → アニメーション → リセット

### 分析フロー
1. 画面を開くと自動でデータ読み込み
2. 健康スコアが即座に表示
3. スクロールで各種グラフを閲覧
4. プルトゥリフレッシュで更新

## 🛠️ 技術スタック

- **フレームワーク**: Flutter 3.x
- **状態管理**: StatefulWidget (シンプルなプロトタイプのため)
- **ストレージ**: shared_preferences
- **依存関係**:
  - `uuid`: ^4.3.3
  - `intl`: ^0.19.0
  - `shared_preferences`: ^2.2.2
